## What is a PAT(Personal Access Token) in GitHub:

1. PAT can be 2 types: `Fine-Grained Tokens` & `Token(Classic)`
2. To generate PAT, follow below steps -
    1. click on profile image, placed in top right corner of the GitHub page
    2. click on "Settings" -> "Developer Settings" -> "Personal access tokens"
    3. Create  `Fine-Grained Tokens` with specific repo, mention expiration duration
    4. Provide below **Repository Permissions**:
        - Contents: Read and write
        - Metadata: Read-only
        - Pull requests: Read and write
    5. Generate token and copy it.
